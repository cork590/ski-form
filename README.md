# スキーフォーム解析

お手本（モデル）の滑りと自分の滑りを比べて、差と改善ポイントを表示するWebアプリです。
骨格推定（MediaPipe Pose）はブラウザ内で動くので、動画が外部に送られることはありません。

## 公開版

GitHub Pages で公開しています。URLを知っているメンバーだけで使ってください。
お手本動画や解析結果は各自のブラウザ内に保存され、サーバーには送られません。

## ローカルで起動

`起動.command` をダブルクリックするか、次を実行します。

```sh
cd "/Volumes/SN770/開発/個人アプリ/スキーフォーム解析"
python3 -m http.server 8000
```

ブラウザ（Chrome推奨）で http://localhost:8000 を開きます。

## 使い方

1. お手本動画を登録します（骨格データと一緒にブラウザ内に保存されます）。
2. 自分の動画を選んで「解析して比較」を押します。
3. 改善アドバイス、局面ごとの差、ターン中の推移グラフが表示されます。

## 構成

- `js/pose.js` … 動画から骨格を抽出（15fps）
- `js/analysis.js` … 体基準の指標の計算、ターン検出、比較、アドバイスのルール
- `js/draw.js` … 骨格のオーバーレイとグラフ
- `js/db.js` … お手本の保存（IndexedDB）
- `js/main.js` … 画面の制御
